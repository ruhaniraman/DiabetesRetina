## A. Referable DR: integrated pipeline vs single techniques

Each model is fitted on the validation split only (APTOS 550 + IDRiD 61 photographs) and evaluated once on the held-out test sets. The threshold is the one that reaches 99% sensitivity on validation (the rule the deployed threshold was chosen by).

| Model | Test set | AUC (95% CI) | Sensitivity | Specificity |
|---|---|---|---|---|
| CNN alone (deployed Stage 3) | APTOS (548) | 0.977 (0.965-0.987) | 96.9% | 88.3% |
| Lesion network alone (Stage 2 U-Net features) | APTOS (548) | 0.964 (0.950-0.976) | 96.0% | 82.2% |
| Rule-based lesion detector alone (classical) | APTOS (548) | 0.835 (0.799-0.868) | 97.8% | 1.8% |
| Integrated: CNN + lesion network | APTOS (548) | 0.979 (0.968-0.987) | 96.9% | 88.9% |
| CNN alone (deployed Stage 3) | IDRID (103) | 0.922 (0.864-0.967) | 90.6% | 53.8% |
| Lesion network alone (Stage 2 U-Net features) | IDRID (103) | 0.909 (0.844-0.960) | 87.5% | 69.2% |
| Rule-based lesion detector alone (classical) | IDRID (103) | 0.458 (0.336-0.572) | 100.0% | 0.0% |
| Integrated: CNN + lesion network | IDRID (103) | 0.917 (0.857-0.964) | 87.5% | 64.1% |

- **APTOS: integrated minus CNN alone, AUC +0.001 (95% CI -0.002 to +0.005); share of bootstrap samples where it is not better: 0.23.**
- **IDRID: integrated minus CNN alone, AUC -0.005 (95% CI -0.023 to +0.013); share of bootstrap samples where it is not better: 0.74.**

**Reading this.**
- The trained pipeline beats the classical single technique by a wide margin: the rule-based lesion detector is barely better than chance on APTOS and no better than chance on IDRiD, and at 99% sensitivity it flags almost every eye.
- The lesion network on its own is nearly as good as the CNN, which is independent evidence that both see the disease.
- Adding the lesion network's features to the CNN **does not measurably improve the referral decision**: the AUC difference is within noise on both test sets. The problem statement asks for the integrated pipeline to beat single techniques; on these data it beats the classical technique and matches, but does not beat, the CNN alone. What the integration adds is evidence a reviewer can check (lesion marks, ICDR criteria), not accuracy.
