# Stage 3 input pipeline: what changes when the image is prepared differently

Generated by `validation/analyze_stage3_pipeline.py`. The deployed network is unchanged; only how each photo is prepared (and, for `crop_mirror`, averaging with the mirror image) differs. `resize` is what the app did before this change.

Thresholds marked *chosen* are picked on APTOS **validation** only (highest threshold with validation sensitivity >= 95%) and then applied unchanged to APTOS test and IDRiD. IDRiD was looked at while these methods were being explored, so its numbers are directional, not a clean held-out result.

## Why does cropping help on IDRiD? (IDRiD only, 516 photographs, threshold 0.20)

| Preparation | What it does | AUC | Sensitivity | Specificity |
|---|---|---|---|---|
| resize | whole 3:2 frame squashed to a square | 0.900 | 94.4% (91.4-96.4) | 46.1% (39.2-53.2) |
| pad | whole frame padded to a square (no distortion, black borders kept) | 0.915 | 92.0% (88.5-94.4) | 59.6% (52.5-66.3) |
| cropsquash | black border cropped, then stretched to a square (distorted) | 0.914 | 91.0% (87.4-93.7) | 65.8% (58.9-72.1) |
| crop | black border cropped, padded to a square (no distortion) | 0.924 | 92.0% (88.5-94.4) | 65.8% (58.9-72.1) |
